## 2. Khái niệm về Socket

Socket (ổ cắm) là một **điểm cuối (endpoint)** trong liên kết giao tiếp hai chiều giữa hai chương trình chạy trên mạng.

Một socket được ràng buộc với:

- Địa chỉ IP
- Số cổng (Port)

Nhờ đó, tầng TCP (Transmission Control Protocol) có thể xác định **ứng dụng nào sẽ nhận dữ liệu**.

### Mô hình Client – Server

- **Server Socket:**  
  Lắng nghe các yêu cầu kết nối từ Client trên một cổng xác định.
- **Client Socket:**  
  Chủ động kết nối đến Server thông qua IP và Port.

## 3. Các loại Socket trong Java

Gói thư viện `java.net` cung cấp hai loại Socket chính:

---

### 3.1. Stream Socket (TCP)

- Sử dụng giao thức **TCP**
- Đảm bảo:
  - Truyền dữ liệu tin cậy
  - Đúng thứ tự
  - Không mất gói

📌 Phù hợp cho:

- Web Server
- Email
- Truyền file

**Class đại diện:**

- `java.net.Socket`
- `java.net.ServerSocket`

---

### 3.2. Datagram Socket (UDP)

- Sử dụng giao thức **UDP**
- Không thiết lập kết nối (connectionless)
- Không đảm bảo:
  - Thứ tự gói tin
  - Độ tin cậy

📌 Phù hợp cho:

- Game online
- Video streaming
- Ứng dụng thời gian thực

**Class đại diện:**

- `java.net.DatagramSocket`
- `java.net.DatagramPacket`

## 4. Cách hoạt động của TCP Socket

Quy trình giao tiếp TCP Socket:

1. Server tạo `ServerSocket` và lắng nghe cổng
2. Server gọi `accept()` (blocking)
3. Client tạo `Socket` và gửi yêu cầu kết nối
4. Server trả về `Socket` riêng cho Client
5. Hai bên trao đổi dữ liệu qua `InputStream` / `OutputStream`
6. Đóng kết nối bằng `close()`

### 5.1. Server.java

```java
import java.io.*;
import java.net.*;

public class ServerExample {
    public static void main(String[] args) {
        try (ServerSocket serverSocket = new ServerSocket(5000)) {
            System.out.println("Server đang lắng nghe tại cổng 5000...");

            Socket socket = serverSocket.accept();
            System.out.println("Client đã kết nối!");

            BufferedReader reader = new BufferedReader(
                    new InputStreamReader(socket.getInputStream()));
            PrintWriter writer = new PrintWriter(
                    socket.getOutputStream(), true);

            String text;
            while ((text = reader.readLine()) != null) {
                System.out.println("Nhận từ Client: " + text);
                writer.println("Server đã nhận: " + text);

                if ("bye".equalsIgnoreCase(text)) {
                    break;
                }
            }

            socket.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```
