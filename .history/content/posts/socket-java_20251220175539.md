                    <h2 class="section-header">2. Khái niệm về Socket</h2>
                    <p>
                        Socket (ổ cắm mạng) là một điểm cuối <em>(endpoint)</em> trong kênh giao tiếp hai chiều giữa hai chương trình chạy trên mạng.
                        Mỗi socket được gắn với một địa chỉ IP và một số cổng <strong>(port)</strong>, giúp tầng TCP có thể định danh chính xác tiến trình cần gửi/nhận dữ liệu.
                    </p>

                    <p class="sub-header">Trong mô hình Client–Server:</p>

                    <ul class="enhanced-list">
                        <li>
                            <span class="list-main">Server Socket:</span>
                            <span class="list-sub">Lắng nghe các yêu cầu kết nối từ client trên một cổng cụ thể, chấp nhận kết nối và tạo socket con để giao tiếp.</span>
                        </li>
                        <li>
                            <span class="list-main">Client Socket:</span>
                            <span class="list-sub">Khởi tạo kết nối đến server thông qua địa chỉ IP và cổng mà server đang lắng nghe, sau đó gửi/nhận dữ liệu qua kết nối này.</span>
                        </li>
                    </ul>

                <section>
                    <h2 class="section-header">3. Các loại Socket trong Java</h2>
                    <p>
                        Gói thư viện <code>java.net</code> cung cấp hai loại socket chính dựa trên giao thức truyền tải.
                    </p>

                    <h3 class="sub-header">3.1. Stream Socket (TCP)</h3>
                    <p>
                        Stream Socket sử dụng giao thức <strong>TCP (Transmission Control Protocol)</strong>.
                        TCP đảm bảo dữ liệu được truyền đi một cách tin cậy, đúng thứ tự và không bị mất gói,
                        rất phù hợp với các ứng dụng yêu cầu độ chính xác cao như web server, email, truyền file.
                    </p>
                    <ul class="enhanced-list">
                        <li>
                            <span class="list-main">Class chính:</span>
                            <span class="list-sub"><code>java.net.Socket</code>, <code>java.net.ServerSocket</code></span>
                        </li>
                    </ul>

                    <h3 class="sub-header">3.2. Datagram Socket (UDP)</h3>
                    <p>
                        Datagram Socket sử dụng giao thức <strong>UDP (User Datagram Protocol)</strong>.
                        UDP không thiết lập kết nối, dữ liệu được gửi đi dưới dạng các gói tin độc lập,
                        không đảm bảo thứ tự cũng như độ tin cậy nhưng bù lại có độ trễ rất thấp.
                    </p>
                    <ul class="enhanced-list">
                        <li>
                            <span class="list-main">Class chính:</span>
                            <span class="list-sub"><code>java.net.DatagramSocket</code>, <code>java.net.DatagramPacket</code></span>
                        </li>
                    </ul>

                <section>
                    <h2 class="section-header">4. Cách hoạt động của TCP Socket</h2>
                    <p>
                        Quy trình giao tiếp cơ bản giữa client và server thông qua TCP Socket thường diễn ra theo các bước sau.
                    </p>

                    <ol class="enhanced-list" style="list-style-type: decimal;">
                        <li>Server khởi tạo đối tượng <code>ServerSocket</code> và chỉ định một cổng (port) để lắng nghe.</li>
                        <li>Server gọi <code>accept()</code> và chờ kết nối – đây là lời gọi <em>blocking</em>.</li>
                        <li>Client khởi tạo đối tượng <code>Socket</code>, chỉ định IP và cổng của server để yêu cầu kết nối.</li>
                        <li>Khi kết nối thành công, server trả về một đối tượng <code>Socket</code> mới dùng riêng cho client đó.</li>
                        <li>Cả hai bên sử dụng <code>InputStream</code> / <code>OutputStream</code> trên socket để gửi và nhận dữ liệu.</li>
                        <li>Sau khi hoàn tất, mỗi bên gọi <code>close()</code> để đóng kết nối và giải phóng tài nguyên.</li>
                    </ol>

<span class="keyword">import</span> java.net.<span class="keyword">\*</span>;

<span class="keyword">public class</span> ServerExample {
<span class="keyword">public static void</span> main(String[] args) {
<span class="keyword">try</span> (ServerSocket serverSocket = <span class="keyword">new</span> ServerSocket(5000)) {
<span class="comment">// Server lắng nghe tại cổng 5000</span>
System.out.println(<span class="string">"Server đang lắng nghe tại cổng 5000..."</span>);

                    <span class="keyword">break</span>;
                }
            }

            socket.close();
        } <span class="keyword">catch</span> (IOException ex) {
            System.out.println(<span class="string">"Lỗi Server: "</span> + ex.getMessage());
            ex.printStackTrace();
        }
    }

}</pre>

<span class="keyword">public static void</span> main(String[] args) {

PrintWriter writer = <span class="keyword">new</span> PrintWriter(socket.getOutputStream(), <span class="keyword">true</span>);

        } <span class="keyword">catch</span> (IOException ex) {
            System.out.println(<span class="string">"Lỗi I/O: "</span> + ex.getMessage());
        }
    }

}</pre>

                    <h2 class="section-header">7. Ứng dụng thực tế</h2>
                    <p>
                        Java Socket là nền tảng cho rất nhiều hệ thống mạng trong thực tế. Một số ví dụ điển hình:
                    </p>

                    <ul class="enhanced-list">
                        <li>
                            <span class="list-main">Hệ thống Chat:</span>
                            <span class="list-sub">Xây dựng ứng dụng nhắn tin thời gian thực dạng console hoặc GUI, nơi nhiều client kết nối tới một server trung tâm để trao đổi tin nhắn.</span>
                        </li>
                        <li>
                            <span class="list-main">Truyền File (FTP đơn giản):</span>
                            <span class="list-sub">Tạo server cho phép client gửi/nhận file nhị phân, áp dụng thêm cơ chế xác thực và phân quyền.</span>
                        </li>
                        <li>
                            <span class="list-main">Web Server tự xây:</span>
                            <span class="list-sub">Hiện thực một HTTP server đơn giản lắng nghe trên cổng 80/8080, đọc HTTP request và trả về HTML response thủ công.</span>
                        </li>
                        <li>
                            <span class="list-main">Remote Control / Monitoring:</span>
                            <span class="list-sub">Điều khiển từ xa một service (bật/tắt, gửi lệnh) hoặc thu thập log, trạng thái hệ thống qua mạng nội bộ.</span>
                        </li>
                        <li>
                            <span class="list-main">Game Multiplayer:</span>
                            <span class="list-sub">Đồng bộ trạng thái game giữa nhiều người chơi, ví dụ gửi vị trí nhân vật, hành động, sự kiện trong game.</span>
                        </li>
                    </ul>
                </section>

                <!-- Usage Notes -->
                <section>
                    <h2 class="section-header">8. Lưu ý khi sử dụng</h2>

                    <div class="quote-block">
                        <p>Luôn quản lý tài nguyên cẩn thận: socket, stream và thread phải được đóng/giải phóng đúng lúc.</p>
                    </div>

                    <ul class="enhanced-list">
                        <li>
                            <span class="list-main">Xử lý ngoại lệ:</span>
                            <span class="list-sub">Mạng rất dễ xảy ra lỗi (mất kết nối, timeout, server down). Cần bao phủ code bằng <code>try-catch</code> phù hợp và log lỗi rõ ràng.</span>
                        </li>
                        <li>
                            <span class="list-main">Đa luồng (Multithreading):</span>
                            <span class="list-sub">Một <code>ServerSocket</code> cơ bản chỉ phục vụ 1 client tại một thời điểm; muốn phục vụ nhiều client, cần dùng thread per client hoặc thread pool.</span>
                        </li>
                        <li>
                            <span class="list-main">Blocking I/O:</span>
                            <span class="list-sub">Các phương thức như <code>accept()</code>, <code>readLine()</code> là blocking; nếu thiết kế không khéo, có thể làm "treo" cả ứng dụng.</span>
                        </li>
                        <li>
                            <span class="list-main">Bảo mật:</span>
                            <span class="list-sub">Khi triển khai thực tế, nên kết hợp thêm SSL/TLS, xác thực người dùng và mã hóa dữ liệu.</span>
                        </li>
                    </ul>
                </section>
