# Lập Trình Java Socket

**Ngày tạo:** 20 tháng 12 năm 2025
**Chủ đề:** Lập trình mạng, Java Core

---

## 1. Giới thiệu chung

Trong kỷ nguyên số hóa, khả năng giao tiếp giữa các thiết bị và ứng dụng qua mạng là một yêu cầu cốt lõi. Java Socket là một trong những cơ chế nền tảng giúp các nhà phát triển thực hiện điều này. Bài viết này sẽ đi sâu vào khái niệm, cấu trúc và cách triển khai Java Socket để xây dựng các ứng dụng mạng hiệu quả.

## 2. Khái niệm về Socket

Socket (ổ cắm) là một điểm cuối (endpoint) trong liên kết giao tiếp hai chiều giữa hai chương trình chạy trên mạng. Một socket được ràng buộc với một số cổng (port number) để tầng TCP (Transmission Control Protocol) có thể định danh ứng dụng mà dữ liệu được gửi đến.

Trong mô hình Client-Server:

- **Server Socket:** Lắng nghe các yêu cầu kết nối từ Client trên một cổng cụ thể.
- **Client Socket:** Khởi tạo kết nối đến Server thông qua địa chỉ IP và số cổng mà Server đang lắng nghe.

## 3. Các loại Socket trong Java

Gói thư viện `java.net` cung cấp hai loại socket chính dựa trên giao thức truyền tải:

### 3.1. Stream Sockets (TCP)

Sử dụng giao thức TCP (Transmission Control Protocol). Loại này đảm bảo dữ liệu được truyền đi một cách tin cậy, đúng thứ tự và không bị lỗi. Đây là loại socket phổ biến nhất cho các ứng dụng yêu cầu độ chính xác cao như web server, email, truyền file.

- Class đại diện: `java.net.Socket` và `java.net.ServerSocket`.

### 3.2. Datagram Sockets (UDP)

Sử dụng giao thức UDP (User Datagram Protocol). Loại này không thiết lập kết nối (connectionless), dữ liệu được gửi đi dưới dạng các gói tin độc lập. Không đảm bảo thứ tự hoặc độ tin cậy nhưng tốc độ nhanh hơn. Thường dùng cho video streaming, game online.

- Class đại diện: `java.net.DatagramSocket` và `java.net.DatagramPacket`.

## 4. Cách hoạt động của TCP Socket

Quy trình giao tiếp cơ bản giữa Client và Server thông qua TCP Socket diễn ra theo các bước sau:

1. Server khởi tạo đối tượng `ServerSocket` và chỉ định một cổng (port) để lắng nghe.
2. Server gọi phương thức `accept()` và chờ đợi kết nối. Phương thức này sẽ chặn (block) luồng thực thi cho đến khi có một client kết nối.
3. Client khởi tạo đối tượng `Socket`, chỉ định địa chỉ IP và cổng của Server để yêu cầu kết nối.
4. Khi kết nối được thiết lập, Server trả về một đối tượng `Socket` mới để giao tiếp riêng với Client đó.
5. Cả hai bên sử dụng các luồng nhập/xuất (InputStream/OutputStream) từ đối tượng Socket để gửi và nhận dữ liệu.
6. Sau khi hoàn tất, cả hai bên đóng kết nối bằng phương thức `close()`.

## 5. Ví dụ minh họa: Ứng dụng Chat đơn giản (TCP)

_Hình 4: Luồng hoạt động của Socket Programming trong Java_

### 5.1. Mã nguồn phía Server (Server.java)

```java
import java.io.*;
import java.net.*;

public class ServerExample {
    public static void main(String[] args) {
        try (ServerSocket serverSocket = new ServerSocket(5000)) {
            System.out.println("Server đang lắng nghe tại cổng 5000...");

            // Chờ kết nối từ Client
            Socket socket = serverSocket.accept();
            System.out.println("Client đã kết nối!");

            // Tạo luồng nhập/xuất dữ liệu
            InputStream input = socket.getInputStream();
            BufferedReader reader = new BufferedReader(new InputStreamReader(input));

            OutputStream output = socket.getOutputStream();
            PrintWriter writer = new PrintWriter(output, true);

            // Đọc tin nhắn từ Client và phản hồi
            String text;
            while ((text = reader.readLine()) != null) {
                System.out.println("Nhận từ Client: " + text);
                writer.println("Server đã nhận: " + text);

                if ("bye".equalsIgnoreCase(text)) {
                    break;
                }
            }

            socket.close();
        } catch (IOException ex) {
            System.out.println("Lỗi Server: " + ex.getMessage());
            ex.printStackTrace();
        }
    }
}
```

### 5.2. Mã nguồn phía Client (Client.java)

```java
import java.io.*;
import java.net.*;
import java.util.Scanner;

public class ClientExample {
    public static void main(String[] args) {
        // Kết nối đến localhost cổng 5000
        try (Socket socket = new Socket("localhost", 5000)) {

            // Luồng để gửi dữ liệu đi
            PrintWriter writer = new PrintWriter(socket.getOutputStream(), true);

            // Luồng để nhận dữ liệu về
            BufferedReader reader = new BufferedReader(new InputStreamReader(socket.getInputStream()));

            Scanner scanner = new Scanner(System.in);
            String text;

            do {
                System.out.print("Nhập tin nhắn: ");
                text = scanner.nextLine();

                // Gửi tin nhắn
                writer.println(text);

                // Nhận phản hồi
                String response = reader.readLine();
                System.out.println(response);

            } while (!"bye".equalsIgnoreCase(text));

        } catch (UnknownHostException ex) {
            System.out.println("Không tìm thấy Server: " + ex.getMessage());
        } catch (IOException ex) {
            System.out.println("Lỗi I/O: " + ex.getMessage());
        }
    }
}
```

## 6. Các phương thức quan trọng cần nhớ

| Class            | Phương thức         | Mô tả ngắn                                                      |
| ---------------- | ------------------- | --------------------------------------------------------------- |
| **ServerSocket** | `accept()`          | Chờ và nhận kết nối mới, trả về một `Socket` dùng để giao tiếp. |
|                  | `close()`           | Đóng server socket, giải phóng cổng đang sử dụng.               |
| **Socket**       | `getInputStream()`  | Lấy luồng để đọc dữ liệu từ phía bên kia (client/server).       |
|                  | `getOutputStream()` | Lấy luồng để ghi dữ liệu gửi sang phía bên kia.                 |
|                  | `close()`           | Đóng kết nối socket.                                            |

## 7. Ứng dụng thực tế

Java Socket là nền tảng cho rất nhiều ứng dụng mạng trong thực tế:

- **Hệ thống Chat:** Ứng dụng nhắn tin tức thời (như ví dụ trên).
- **Truyền File (FTP):** Xây dựng các ứng dụng gửi và nhận file giữa các máy tính.
- **Web Server:** Các máy chủ web cơ bản xử lý HTTP request đều dựa trên socket.
- **Remote Method Invocation (RMI):** Java RMI sử dụng socket bên dưới để gọi phương thức từ xa.
- **Game Multiplayer:** Đồng bộ trạng thái game giữa các người chơi.

## 8. Lưu ý khi sử dụng

> **Quản lý Tài nguyên:** Luôn luôn đóng socket (sử dụng khối `try-with-resources` hoặc khối `finally`) sau khi sử dụng để tránh rò rỉ tài nguyên hệ thống.

Ngoài ra, cần lưu ý các điểm sau:

- **Xử lý ngoại lệ:** Lập trình mạng rất dễ xảy ra lỗi (mất mạng, server chết, timeout). Cần xử lý kỹ các `IOException`.
- **Đa luồng (Multithreading):** ServerSocket cơ bản chỉ xử lý một client tại một thời điểm. Để phục vụ nhiều client cùng lúc, cần sử dụng Multithreading (mỗi client một luồng riêng) hoặc Java NIO (Non-blocking I/O).
- **Blocking I/O:** Các phương thức `read()` và `accept()` là các phương thức chặn (blocking). Chương trình sẽ dừng tại đó cho đến khi có dữ liệu hoặc kết nối.

## 9. Kết luận

Java Socket cung cấp một cơ chế mạnh mẽ và linh hoạt để phát triển các ứng dụng mạng. Mặc dù hiện nay có nhiều framework cao cấp hơn (như Netty, Spring Boot) giúp ẩn đi sự phức tạp của socket, việc hiểu rõ cơ chế hoạt động của Socket vẫn là kiến thức nền tảng quan trọng cho bất kỳ lập trình viên Java nào muốn chuyên sâu về hệ thống phân tán và lập trình mạng.
