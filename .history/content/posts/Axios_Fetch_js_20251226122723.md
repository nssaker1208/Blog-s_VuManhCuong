  <h3 class="mt-6 mb-2 text-xl font-semibold">
    2.1. Fetch API: "Hàng chính chủ"
  </h3>

  <p class="mb-4 leading-relaxed text-gray-800" style="text-align: justify;">
    <strong>Fetch API</strong> là một Web API native được tích hợp sẵn trong các trình duyệt modern. Nó được thiết kế để thay thế cho XMLHttpRequest và cung cấp một cách hiện đại hơn để thực hiện các HTTP requests.
  </p>

  <p class="mb-3 font-semibold text-gray-900" style="text-align: justify;">
    Đặc điểm:
  </p>

  <ul class="list-disc list-inside space-y-2 mb-6 text-gray-800" style="text-align: justify;">
    <li><strong>Native:</strong> Không cần cài đặt thêm thư viện</li>
    <li><strong>Promise-based:</strong> Hỗ trợ async/await</li>
    <li><strong>Streaming:</strong> Hỗ trợ đọc response theo chunks</li>
    <li><strong>Service Worker friendly:</strong> Hoạt động tốt trong Service Workers</li>
  </ul>

  <h3 class="mt-6 mb-2 text-xl font-semibold">
    Ví dụ cơ bản với Fetch
  </h3>

```javascript
// GET request
const getData = async () => {
  try {
    const response = await fetch("https://api.example.com/users");

    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }

    const data = await response.json();
    return data;
  } catch (error) {
    console.error("Fetch error:", error);
    throw error;
  }
};

// POST request
const createUser = async (userData) => {
  try {
    const response = await fetch("https://api.example.com/users", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
      },
      body: JSON.stringify(userData),
    });

    return await response.json();
  } catch (error) {
    console.error("Create user error:", error);
    throw error;
  }
};
```

  <h3 class="mt-6 mb-2 text-xl font-semibold">
    2.2. Axios: "Vũ khí hạng nặng"
  </h3>

  <p class="mb-4 leading-relaxed text-gray-800" style="text-align: justify;">
    <strong>Axios</strong> là một thư viện HTTP client phổ biến được xây dựng dựa trên XMLHttpRequest cho browsers và http cho Node.js. Nó cung cấp nhiều tính năng mạnh mẽ mà Fetch API chưa có sẵn. Nghĩa là một thư viện HTTP Client bên thứ 3. Bản chất nó vẫn chạy trên <code>XMLHttpRequest</code> ở trình duyệt và <code>http</code> module ở Node.js, nhưng được bọc lại với nhiều tính năng tiện ích (Syntactic Sugar).
  </p>

  <h3 class="mt-6 mb-2 text-xl font-semibold">
    3.1. Cú pháp và xử lý JSON
  </h3>

  <p class="mb-4 leading-relaxed text-gray-800" style="text-align: justify;">
    Giả sử chúng ta muốn lấy danh sách user từ API.
  </p>

  <p class="mb-3 font-semibold text-gray-900" style="text-align: justify;">
    Với Fetch:
  </p>

  <p class="mb-4 leading-relaxed text-gray-800" style="text-align: justify;">
    Bạn phải qua 2 bước <code>await</code>. Một để lấy response, một để parse body thành JSON.
  </p>

```javascript
// Fetch
async function getUsers() {
  try {
    const response = await fetch(
      "[https://api.example.com/users](https://api.example.com/users)"
    );
    const data = await response.json(); // Phải thủ công parse JSON
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}
```

  <p class="mt-4 mb-3 font-semibold text-gray-900" style="text-align: justify;">
    Với Axios:
  </p>

  <p class="mb-4 leading-relaxed text-gray-800" style="text-align: justify;">
    Axios tự động biến đổi JSON cho bạn. Kết quả trả về nằm gọn trong property <code>data</code>.
  </p>

```javascript
// Axios
import axios from "axios";

async function getUsers() {
  try {
    const response = await axios.get(
      "[https://api.example.com/users](https://api.example.com/users)"
    );
    console.log(response.data); // JSON đã sẵn sàng, không cần parse
  } catch (error) {
    console.error(error);
  }
}
```

  <h3 class="mt-6 mb-2 text-xl font-semibold">
    3.2. Xử lý lỗi (Error Handling) - Điểm chí mạng
  </h3>

  <p class="mb-4 leading-relaxed text-gray-800" style="text-align: justify;">
    Đây là lý do lớn nhất khiến nhiều người (trong đó có mình) vẫn ưu ái Axios.
  </p>

  <ul class="list-disc list-inside space-y-2 mb-6 text-gray-800" style="text-align: justify;">
    <li>
      <strong>Fetch:</strong> Chỉ coi là "Lỗi" (reject promise) khi mất mạng hoặc lỗi DNS. Nếu server trả về 404 hay 500, Fetch vẫn coi là thành công! Bạn phải tự check thủ công.
    </li>
    <li>
      <strong>Axios:</strong> Tự động reject promise nếu status code nằm ngoài khoảng 2xx.
    </li>
  </ul>

  <div class="flex flex-col items-center my-6" style="text-align: center;">
    <img
      src="https://copilot.microsoft.com/th/id/BCO.4605b5e4-1410-4fae-9aab-0c4ac36115c9.png"
      alt="Error Handling Flow"
      class="max-w-full h-auto rounded shadow-md transition-opacity duration-700 ease-out"
    >
    <p class="text-sm text-gray-500 mt-2" style="font-style: italic; font-weight: 600;">
      Hình 2: Luồng xử lý lỗi. Fetch đòi hỏi phải viết thêm logic if (!res.ok), Axios tự động ném lỗi vào catch
    </p>
  </div>

  <p class="mb-3 font-semibold text-gray-900" style="text-align: justify;">
    Code so sánh:
  </p>

```javascript
// Fetch: Phải tự check
const res = await fetch(url);
if (!res.ok) {
  // 404, 500 sẽ chui vào đây
  throw new Error("Lỗi rồi: " + res.status);
}

// Axios: Tự động bắt
try {
  await axios.get(url);
} catch (err) {
  // 404, 500 tự động chui vào đây
  console.log(err.response.status);
}
```

  <h2 class="mt-10 mb-3 text-2xl md:text-3xl font-bold tracking-tight">
    4. Các tính năng "Ăn tiền" của Axios
  </h2>

  <p class="mb-4 leading-relaxed text-gray-800" style="text-align: justify;">
    Nếu chỉ vì cú pháp ngắn hơn một chút, có lẽ Axios không phổ biến đến thế. Sức mạnh thực sự của nó nằm ở những tính năng nâng cao mà Fetch làm rất cực khổ.
  </p>

  <h3 class="mt-6 mb-2 text-xl font-semibold">
    4.1. Interceptors (Đánh chặn)
  </h3>

  <p class="mb-4 leading-relaxed text-gray-800" style="text-align: justify;">
    Đây là tính năng "Killer Feature". Interceptors cho phép bạn can thiệp vào request hoặc response trước khi chúng được xử lý bởi <code>then</code> hoặc <code>catch</code>.
  </p>

  <p class="mb-4 leading-relaxed text-gray-800" style="text-align: justify;">
    <strong>Use-case:</strong> Tự động đính kèm Token vào mọi request, hoặc tự động logout khi gặp lỗi 401.
  </p>

  <div class="flex flex-col items-center my-6" style="text-align: center;">
    <img
      src="https://copilot.microsoft.com/th/id/BCO.a1a191f9-a17c-4fa4-9203-2e4316aa2dff.png"
      alt="Axios Interceptors"
      class="max-w-full h-auto rounded shadow-md"
    >
    <p class="text-sm text-gray-500 mt-2" style="font-style: italic; font-weight: 600;">
      Hình 3: Cơ chế Interceptor hoạt động giống như chốt bảo vệ. Mọi request đều phải qua chốt kiểm tra này
    </p>
  </div>

```javascript
// Axios Interceptors - Request
axios.interceptors.request.use((config) => {
    // Tự động thêm token vào mọi request
    const token = localStorage.getItem('token');
    if (token) {
        config.headers.Authorization = Bearer ${token};
    }
    return config;
},(error) => return Promise.reject(error);
);

// Axios Interceptors - Response
axios.interceptors.response.use(
    (response) => response, (error) => {
        // Tự động logout khi token hết hạn
        if (error.response?.status === 401) {
            localStorage.removeItem('token');
            window.location.href = '/login';
        }
        return Promise.reject(error);
    }
);
```

  <p class="mt-4 mb-4 leading-relaxed text-gray-800" style="text-align: justify;">
    Với Fetch, bạn phải viết các hàm wrapper (Higher Order Functions) bao bọc lấy hàm <code>fetch</code> gốc rất phức tạp mới làm được điều tương tự.
  </p>

  <h3 class="mt-6 mb-2 text-xl font-semibold">
    4.2. Request Timeout
  </h3>

  <ul class="list-disc list-inside space-y-2 mb-4 text-gray-800" style="text-align: justify;">
    <li><strong>Axios:</strong> <code>axios.get(url, { timeout: 3000 })</code> - Quá đơn giản</li>
    <li><strong>Fetch:</strong> Bạn phải dùng <code>AbortController</code></li>
  </ul>

```javascript
// Axios - Đơn giản
axios
  .get(url, { timeout: 3000 })
  .then((response) => console.log(response.data))
  .catch((error) => {
    if (error.code === "ECONNABORTED") {
      console.log("Request timeout!");
    }
  });

// Fetch Timeout - Khá cồng kềnh
const controller = new AbortController();
const timeoutId = setTimeout(() => controller.abort(), 3000);

try {
  const response = await fetch(url, { signal: controller.signal });
  clearTimeout(timeoutId);
  const data = await response.json();
} catch (error) {
  if (error.name === "AbortError") {
    console.log("Request timeout!");
  }
}
```
