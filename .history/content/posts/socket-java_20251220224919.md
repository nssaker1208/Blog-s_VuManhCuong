## 1. Giới thiệu chung

Trong kỷ nguyên số hóa, khả năng giao tiếp giữa các thiết bị và ứng dụng qua mạng là một yêu cầu cốt lõi. Java Socket là một trong những cơ chế nền tảng giúp các nhà phát triển hiện thực hóa điều này. Bài viết này đi sâu vào khái niệm, cấu trúc và cách triển khai Java Socket để xây dựng các ứng dụng mạng hiệu quả, dễ mở rộng.

## 2. Khái niệm về Socket

Socket (ổ cắm mạng) là một điểm cuối _(endpoint)_ trong kênh giao tiếp hai chiều giữa hai chương trình chạy trên mạng. Mỗi socket được gắn với một địa chỉ IP và một số cổng **(port)**, giúp tầng TCP có thể định danh chính xác tiến trình cần gửi/nhận dữ liệu.

Trong mô hình Client–Server:

- **Server Socket:** Lắng nghe các yêu cầu kết nối từ client trên một cổng cụ thể, chấp nhận kết nối và tạo socket con để giao tiếp.
- **Client Socket:** Khởi tạo kết nối đến server thông qua địa chỉ IP và cổng mà server đang lắng nghe, sau đó gửi/nhận dữ liệu qua kết nối này.

## 3. Các loại Socket trong Java

Gói thư viện `java.net` cung cấp hai loại socket chính dựa trên giao thức truyền tải.

### 3.1. Stream Socket (TCP)

Stream Socket sử dụng giao thức **TCP (Transmission Control Protocol)**. TCP đảm bảo dữ liệu được truyền đi một cách tin cậy, đúng thứ tự và không bị mất gói, rất phù hợp với các ứng dụng yêu cầu độ chính xác cao như web server, email, truyền file.

- **Class chính:** `java.net.Socket`, `java.net.ServerSocket`.

### 3.2. Datagram Socket (UDP)

Datagram Socket sử dụng giao thức **UDP (User Datagram Protocol)**. UDP không thiết lập kết nối, dữ liệu được gửi đi dưới dạng các gói tin độc lập, không đảm bảo thứ tự cũng như độ tin cậy nhưng bù lại có độ trễ rất thấp.

- **Class chính:** `java.net.DatagramSocket`, `java.net.DatagramPacket`.

## 4. Cách hoạt động của TCP Socket

Quy trình giao tiếp cơ bản giữa client và server thông qua TCP Socket thường diễn ra theo các bước sau:

1. Server khởi tạo đối tượng `ServerSocket` và chỉ định một cổng (port) để lắng nghe.
2. Server gọi `accept()` và chờ kết nối – đây là lời gọi _blocking_.
3. Client khởi tạo đối tượng `Socket`, chỉ định IP và cổng của server để yêu cầu kết nối.
4. Khi kết nối thành công, server trả về một đối tượng `Socket` mới dùng riêng cho client đó.
5. Cả hai bên sử dụng `InputStream` / `OutputStream` trên socket để gửi và nhận dữ liệu.
6. Sau khi hoàn tất, mỗi bên gọi `close()` để đóng kết nối và giải phóng tài nguyên.

### 5.1. Mã nguồn phía Server (ServerExample.java)

```java
import java.io.;
import java.net.;
public class ServerExample {
public static void main(String[] args) {
try (ServerSocket serverSocket = new ServerSocket(5000)) {
System.out.println("Server đang lắng nghe tại cổng 5000...");
// Chờ kết nối từ Client
        Socket socket = serverSocket.accept();
        System.out.println("Client đã kết nối!");

        // Tạo luồng nhập/xuất dữ liệu
        InputStream input = socket.getInputStream();
        BufferedReader reader = new BufferedReader(new InputStreamReader(input));

        OutputStream output = socket.getOutputStream();
        PrintWriter writer = new PrintWriter(output, true);

        // Đọc tin nhắn từ Client và phản hồi
        String text;
        while ((text = reader.readLine()) != null) {
            System.out.println("Nhận từ Client: " + text);
            writer.println("Server đã nhận: " + text);

            if ("bye".equalsIgnoreCase(text)) {
                break;
            }
        }

        socket.close();
    } catch (IOException ex) {
        System.out.println("Lỗi Server: " + ex.getMessage());
        ex.printStackTrace();
    }
}
}
```

### 5.2. Mã nguồn phía Client (ClientExample.java)

```java
import java.io.;
import java.net.;
import java.util.Scanner;
public class ClientExample {
public static void main(String[] args) {
// Kết nối đến localhost cổng 5000
try (Socket socket = new Socket("localhost", 5000)) {
// Luồng để gửi dữ liệu đi
        PrintWriter writer = new PrintWriter(socket.getOutputStream(), true);

        // Luồng để nhận dữ liệu về
        BufferedReader reader = new BufferedReader(new InputStreamReader(socket.getInputStream()));

        Scanner scanner = new Scanner(System.in);
        String text;

        do {
            System.out.print("Nhập tin nhắn: ");
            text = scanner.nextLine();

            // Gửi tin nhắn
            writer.println(text);

            // Nhận phản hồi
            String response = reader.readLine();
            System.out.println(response);

        } while (!"bye".equalsIgnoreCase(text));

    } catch (UnknownHostException ex) {
        System.out.println("Không tìm thấy Server: " + ex.getMessage());
    } catch (IOException ex) {
        System.out.println("Lỗi I/O: " + ex.getMessage());
    }
}
}
```

## 6. Các phương thức quan trọng

| Class            | Phương thức         | Mô tả                                                                 |
| ---------------- | ------------------- | --------------------------------------------------------------------- |
| **ServerSocket** | `accept()`          | Chờ và chấp nhận kết nối đến, trả về đối tượng `Socket` để giao tiếp. |
|                  | `close()`           | Đóng server socket, giải phóng cổng đang lắng nghe.                   |
| **Socket**       | `getInputStream()`  | Trả về luồng nhập (`InputStream`) để đọc dữ liệu từ socket.           |
|                  | `getOutputStream()` | Trả về luồng xuất (`OutputStream`) để ghi dữ liệu vào socket.         |
|                  | `close()`           | Đóng kết nối socket, giải phóng tài nguyên.                           |

## 7. Ứng dụng thực tế

Java Socket là nền tảng cho rất nhiều hệ thống mạng trong thực tế. Một số ví dụ điển hình:

- **Hệ thống Chat:** Xây dựng ứng dụng nhắn tin thời gian thực dạng console hoặc GUI, nơi nhiều client kết nối tới một server trung tâm để trao đổi tin nhắn.
- **Truyền File (FTP đơn giản):** Tạo server cho phép client gửi/nhận file nhị phân, áp dụng thêm cơ chế xác thực và phân quyền.
- **Web Server tự xây:** Hiện thực một HTTP server đơn giản lắng nghe trên cổng 80/8080, đọc HTTP request và trả về HTML response thủ công.
- **Remote Control / Monitoring:** Điều khiển từ xa một service (bật/tắt, gửi lệnh) hoặc thu thập log, trạng thái hệ thống qua mạng nội bộ.
- **Game Multiplayer:** Đồng bộ trạng thái game giữa nhiều người chơi, ví dụ gửi vị trí nhân vật, hành động, sự kiện trong game.

## 8. Lưu ý khi sử dụng

> **Quản lý Tài nguyên:** Luôn quản lý tài nguyên cẩn thận: socket, stream và thread phải được đóng/giải phóng đúng lúc.

Ngoài ra, cần lưu ý các điểm sau:

- **Xử lý ngoại lệ:** Mạng rất dễ xảy ra lỗi (mất kết nối, timeout, server down). Cần bao phủ code bằng `try-catch` phù hợp và log lỗi rõ ràng.
- **Đa luồng (Multithreading):** Một `ServerSocket` cơ bản chỉ phục vụ 1 client tại một thời điểm; muốn phục vụ nhiều client, cần dùng thread per client hoặc thread pool.
- **Blocking I/O:** Các phương thức như `accept()`, `readLine()` là blocking; nếu thiết kế không khéo, có thể làm "treo" cả ứng dụng.
- **Bảo mật:** Khi triển khai thực tế, nên kết hợp thêm SSL/TLS, xác thực người dùng và mã hóa dữ liệu.

## 9. Kết luận

Java Socket cung cấp nền tảng vững chắc để xây dựng các ứng dụng mạng từ đơn giản đến phức tạp. Dù ngày nay có nhiều framework cao cấp như Netty hay Spring WebFlux, việc hiểu rõ cơ chế hoạt động của Socket vẫn là kiến thức cốt lõi giúp bạn thiết kế hệ thống phân tán hiệu quả và chủ động hơn.
